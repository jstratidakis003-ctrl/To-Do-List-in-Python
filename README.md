Python To-Do List

A simple command-line To-Do List application written in Python.

This project started as a basic task list that could add, remove, edit, complete, and clear tasks. It has now been expanded with a Completed Task List (CTL), automatic backups, support for working with multiple JSON files, and additional task-management commands.

Features
To-Do List (TDL)

The main To-Do List allows you to:

Add new tasks
View all tasks
View a single task
Edit tasks
Remove tasks
Mark tasks as completed
Clear all tasks
Store the task creation time
Store the task completion time
Completed Task List (CTL)

Completed tasks are moved to a separate list.

The Completed Task List allows you to:

View completed tasks
View a single completed task
Remove completed tasks
Clear completed tasks

Completed tasks are stored in:

ctl_tdl.json
